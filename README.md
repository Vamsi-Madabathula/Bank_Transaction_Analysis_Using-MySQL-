# Bank Transaction Analysis Using MySQL

## Project Overview
This project uses MySQL to store and analyse fictional banking transaction data. It focuses on deposits, withdrawals, transaction statuses, and account activity.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- `customers` – customer information
- `accounts` – customer account details
- `transactions` – deposit and withdrawal records

## SQL Concepts
- CREATE DATABASE and CREATE TABLE
- Primary keys and foreign keys
- INSERT and SELECT statements
- WHERE and ORDER BY clauses
- Aggregate functions such as SUM and COUNT
- GROUP BY and LIMIT
- Relational database design

## How to Run
1. Open MySQL Workbench.
2. Open `bank_analysis.sql`.
3. Execute the script to create the database, tables, and sample records.
4. Run the analysis queries to view the results.

## Note
This project uses fictional sample data for learning and demonstration purposes.
